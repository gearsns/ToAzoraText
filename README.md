# to 青空文庫テキスト

to 青空文庫テキスト は、小説サイトにある小説を 青空文庫形式のテキストファイルに変換するbookmarkletです。

iOSが26になり [FileSystemFileHandle.createWritable](https://developer.mozilla.org/ja/docs/Web/API/FileSystemFileHandle/createWritable)に対応したのでブラウザのみで動作する青空文庫形式への変換ツールを作成しました。


![](docs/image/info.gif)

## 使い方

1. サイト：[to 青空文庫テキスト](https://gearsns.github.io/ToAzoraText/index.html) にアクセス

2. 「登録方法」に従い bookmarklet を登録

## 対応サイト

小説家になろう
